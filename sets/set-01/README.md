# Sample Set 01 — Cedar & Fern

A fictional garden studio presented as a cohesive website, iPhone app and desktop tool. Warm neutral backgrounds, fir green, pale lime accents, generous spacing and editorial typography form the shared design direction.

[Explore Set 01](https://recondemon.github.io/henstek-samples/#sample-set-01) · [Customer walkthrough](../../CUSTOMER-WALKTHROUGH.md) · [Verification and limits](../../VERIFICATION.md)

| **Set 01 / iPhone** (`set-01-iphone`) | Field Notes — visits, checklists and notes | [SwiftUI project](../../samples/mobile/README.md) | Run in Xcode; no store release |

Each example works independently with local data; the three do not synchronize. All businesses and records are fictional. Original source and illustration use the repository's [MIT license](../../LICENSE). A commissioned adaptation needs its own scope and production integrations.

Record the **set, platform and source commit** when quoting an adaptation. Set 01 identifies this design direction; alternate designs belong to later numbered sets. Existing source and demo URLs remain stable when more sets are added.
