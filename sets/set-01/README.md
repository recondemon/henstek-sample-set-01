# Sample Set 01 — Cedar & Fern

A fictional garden studio presented as a cohesive website, iPhone app and desktop tool. The shared **Fieldwork** direction combines warm paper and forest ink with lime accents, bold sans-serif type, a botanical emblem and textured garden scenes. The website uses a light canvas; the mobile and desktop tools use a dark working surface.

Each example works independently with local data; the three do not synchronize. All businesses and records are fictional. Source and sample assets use the repository's [MIT license](../../LICENSE). A commissioned adaptation needs its own scope and production integrations.

A client can choose functionality and styling independently: **“CF-01 / Mobile workflow with CF-01 / Web styling.”** The [mixed inquiry](https://henstek.dev/start?sample=set-01-iphone&style=cf-01-web) records these as separate fields. Visual reference IDs are `cf-01-web`, `cf-01-mobile` and `cf-01-desktop`; existing functional IDs remain unchanged.

Record the **functional reference, visual reference and source commit** when quoting an adaptation. Set 01 identifies this design direction; alternate designs belong to later numbered sets. Existing source and demo URLs remain stable when more sets are added.
